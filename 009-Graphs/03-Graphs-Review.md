# Graphs Review

## Graphs Review

| Good                                                       | Bad                             |
| ---------------------------------------------------------- | ------------------------------- |
| **Relationships:** some data can only be stored as a graph | **Hard to scale** (to make big) |
| **Algorithms** like shortest path and traversing a graph   |                                 |

- **Big O:** hard to give one answer, because there are so many types of graphs.
- **Scaling:** big graphs need a big company, or a lot of engineers and money.
- **In real work:** you almost never build your own graph. Tools like **Neo4j** (a popular graph database) do it for you.
- Shortest path and traversing (walking through) a graph come in the algorithms section.

> **Key idea:** Graphs are the best way to store relationships, but they're hard to scale, so in real work you use a tool like Neo4j.
