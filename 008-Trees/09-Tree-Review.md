# Tree Review

## Tree Review

- **There are many types of trees,** but they all work the same way.
- **The only difference is a few small rules.** Example: binary search trees, binary heaps and priority queues.
- **If you can build one tree from scratch,** you can build the others too.
- **Wikipedia's long list of tree types:** each one is just a tree with a few different rules. You can learn any of them with a little research.

> **Key idea:** All trees work the same way. Only the rules change.
